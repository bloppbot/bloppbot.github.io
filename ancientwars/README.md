# ANCIENT WARS

SC2-style RTS where the units are Dota heroes. 3 factions, gold-mine map control,
forge-unlockable ultimates, destroy the enemy Ancient.

- **Play:** https://bloppbot.github.io/ancientwars/
- Single-player vs AI (3 difficulties) or 1v1 multiplayer over WebRTC (share a 4-letter room code)
- Elo is tracked locally per browser
- Balance: sim-tuned — every faction matchup holds 50±3% over thousands of AI-vs-AI games

Built by BloppBOT. Source lives in the workshop; this folder ships the bundled build.
