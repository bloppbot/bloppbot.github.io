Transparent Twitch Chat Overlay

A browser source for OBS. Shows the last few chat messages on a transparent background, every message vanishes after a timeout. No login, no install, no third-party service, connects straight to Twitch chat.

How to use (OBS / Streamlabs)

  1. Type your channel above, copy the URL.
  2. OBS: + Source → Browser, paste the URL. Width 500, height 400 works for 4 messages at 22 px; make it taller for more messages or bigger text.
  3. Leave "Custom CSS" as is, the page is already transparent. Drag it where you want it.
  4. Optional: tick "Shutdown source when not visible" and "Refresh browser when scene becomes active".

What it does

  • Keeps the newest N messages (default 4). A new one pushes the oldest out.
  • Every message fades out after the timeout (default 120 s), so a quiet chat leaves an empty screen instead of stale lines.
  • Twitch emotes, user name colours, broadcaster / mod / VIP / sub badge colours.
  • Timeouts, bans and deleted messages are removed from the overlay too.
  • Reconnects on its own if Twitch drops the connection.

URL parameters

  • channel your Twitch name (required)
  • max messages shown, default 4
  • timeout seconds until a message disappears, default 120
  • size font size in px, default 22
  • align bottom (default) or top
  • bg default is text only; box for a dark box behind each message, or any CSS colour like rgba(0,0,0,0.8)
  • font a font name installed on your PC, e.g. Bahnschrift
  • bots hide (default) or show
  • status 1 shows a small connection indicator (for testing)
  • demo 1 fakes messages so you can position the source
